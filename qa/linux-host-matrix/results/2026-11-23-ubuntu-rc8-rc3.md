# Core RC8 and Node Pro RC3 Ubuntu host drill

On 2026-11-23 (US Central; 2026-11-24 UTC), the [six-job GitHub Actions run](https://github.com/Smccann01/HoneyMesh-Open-Source/actions/runs/45323982570) tested the exact published AMD64 DEBs on separate, disposable Ubuntu VMs. Each package download matched its published `SHA256SUMS` and a source-bound GitHub attestation for commit `6e84eb27d49876f2d405c1a6996173220e1b366e` before installation.

Each host passed package installation, service startup, safe defaults, TEST mode, baseline traffic from two sources, generic XDP attachment to an isolated veth, rejection of blocking in TEST, selected-source blocking in ENFORCE with an increasing drop counter, continued control-source reachability, rule release restoring traffic, return to TEST, and preservation of local state after restart with XDP detached.

This qualifies a **scoped, noncritical VM pilot** for the exact release, Ubuntu version, architecture, and kernel shown. The test did not attach to a production network interface, exercise native XDP or a physical NIC, measure throughput, test long-running reliability, or evaluate the Node Pro application bridge. It does not prove behavior on other kernels of the same Ubuntu release. The 5.9 upstream XDP BPF-link floor was established from the implementation and dependency feature tests; these VMs did not run an upstream 5.9 kernel.
