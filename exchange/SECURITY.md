# Security policy

Report suspected vulnerabilities privately to security@network-decode.com. Include the affected component and version, a clear reproduction, and the possible impact. Do not include live credentials, customer data, or private keys in the report.

Please allow time for a fix and coordinated disclosure before posting exploit details publicly. Security fixes and supported versions will be identified in release notes. Current pilot and alpha components have limited support scopes; consult each component's release documentation before using it on critical systems.

For an actively compromised installation, disable sharing and enforcement as appropriate, isolate affected credentials, and follow your organization's incident response process.
